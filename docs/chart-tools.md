# Interactive chart workspace

The simulator opens a candlestick chart with instrument search above it. Native chart navigation, interval selection, crosshair/OHLC readout, full screen, theme and basic settings are available to Starter.

Sprouty’s tour has 16 steps. Starter can complete steps 1–8. Steps 9–16 explain Pro indicators, drawings, risk planning, replay and advanced overlays. Starter receives an upgrade prompt at the halfway point; it cannot advance into the Pro walkthrough.

Pro includes calculated trend/momentum/volatility indicators, generated volume views, temporary drawing annotations, entry/stop/target planning lines, bar replay, pattern candidates, ticker comparisons and page-local alerts. Stops and targets are planning aids, not automatic orders. Replay does not change current-price order execution. Prices and activity are generated practice data, not exchange quotes or volume; no exchange order book is supplied. Pattern candidates are heuristics. Flag/pennant/triangle analysis uses manual drawings. Alerts require the page to remain open. Lightweight Charts attribution remains visible.

Validation: production build, ESLint, unit tests, and browser tests covering the eight-step Starter lock and complete Pro tour, indicators, drawings, risk, replay and mobile sizing.
